# Formation_of_Earth
This project creates a webpage, showing the history of formation of earth

## Outcome of the project
* To have a knowledge and applications of elements of HTML
* To have an in-depth knowledge of how our planet form since The Big Bang

## Tools used
- HTML
- Notepad ++ (text editor)

## Creation of Internal Hyperlinks
This has been achieved by creating bookmarks and linking them to the link tag.

``` bash
<li><b><a href="#The Big Bang Theory">The Big Bang Theory</a></b></font></ul>
...
<h2 align=center><a name="The Big Bang Theory">The Big Bang Theory</a></h2>
```

## Providing external reference link
This has been done by first creating an 'iframe' and pushing the youtube video

```bash
<iframe width="560" height="315" src="https://www.youtube.com/embed/QLq6GEiHqR8" title="YouTube video player" frameborder="0" allow="accelerometer; autoplay; clipboard-write; encrypted-media; gyroscope; picture-in-picture" allowfullscreen></iframe>
```
